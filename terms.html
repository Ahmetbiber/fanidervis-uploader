FaniDervis Uploader is a personal desktop application operated by the owner of the Fani Derviş YouTube channel. It is not offered to the public.

Data accessed

With the account owner's consent, the app uses Google OAuth to access the YouTube Data API (upload videos, read channel information) and, optionally, Google Drive files created by the app itself (drive.file) to stage videos before upload.

How data is used and stored

OAuth tokens are stored only on the owner's own computer, encrypted with the operating system's credential protection. Video files and metadata are used solely to upload videos to the owner's own channel. No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
